# Radio y Podcast Escolar

Proyecto de la Escuela 21 de Noviembre - Esquipulas.

Lema: Ciencia y Virtud.

Proyecto de Informática del Profechan.

## Secciones

- Cabina: grabación de episodios, sala en vivo con Jitsi y administración.
- Podcast: página pública con los episodios publicados.

## Servicios

- GitHub Pages para la web.
- Jitsi Meet para sala en vivo.
- Supabase para base de datos y almacenamiento de audios.

## Configuración

1. Ejecutar `supabase.sql` en Supabase SQL Editor.
2. Configurar `js/config.js`.
3. Guardar las imágenes en `img/escudo.png` e `img/podcast-icon.png`.
4. Subir el proyecto a GitHub.
5. Activar GitHub Pages.
